# Support

Need help with **Nautora**?

- **Found a bug?** [Open a bug report](../../issues/new?template=bug_report.yml)
- **Want a feature?** [Open a feature request](../../issues/new?template=feature_request.yml)
- **General question?** [Open an issue](../../issues/new/choose) with the closest template

Before filing, please:

1. Update to the latest version of the app.
2. Include your **Nautora version**, **platform** (iOS / Android), **OS version**, and **Portainer version**.
3. **Redact secrets** — never include API keys, tokens, or private server URLs. This tracker is public.
