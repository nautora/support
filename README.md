# Nautora — Support & Privacy

This is the public home for **Nautora**, a [Portainer](https://www.portainer.io/) client for iOS and Android.
The app itself is closed-source; this repository exists so you can **report issues** and read the **privacy policy**.

## 🐛 Report a bug or request a feature

[**Open an issue**](../../issues/new/choose) and pick a template. Please include your Nautora version, platform, and
Portainer version so we can help quickly.

> ⚠️ **Never paste API keys, tokens, or private server addresses** into an issue — this tracker is public.

## 🔒 Privacy

Nautora collects **no** data — no analytics, no tracking, no account, no ads.
Read the full [**Privacy Policy**](https://nautora.github.io/support/privacy/) (source: [`docs/privacy.md`](docs/privacy.md)).
